### 1. Main HTTP server has no read/write/idle timeouts

`internal/server/server.go:102-105`. The `http.Server` is constructed with only `Addr` and `Handler` — no `ReadHeaderTimeout`, `ReadTimeout`, `WriteTimeout`, or `IdleTimeout`. The RateLimit/BodyLimit middleware bound request *size*, but nothing bounds how slowly a client may send headers/body. A classic Slowloris-style attacker opening many connections and trickling bytes can pin goroutines/file descriptors indefinitely, exhausting the listener before any per-IP rate limit is even evaluated (limiting happens inside the handler chain, after the connection is already accepted and the request line/headers are being read). Note the outbound reverse-proxy transport (`internal/handlers/proxy.go`) does set dial/response timeouts — this gap is specific to the inbound listener that every external client talks to. Since SSE routes hold the connection open intentionally, a blanket `WriteTimeout` isn't a drop-in fix, but `ReadHeaderTimeout` (and possibly a bounded `ReadTimeout` on the body-reading phase) is safe to add and is the standard defense here. Severity: Medium.

### 2. `swlib/jwt/jwt.go` `VerifyToken` discards the claim-parsing error

`swlib/jwt/jwt.go:196-197`, surfaced via swayrider-api's JWT verification path (shared code — see [[swlib]] review for the canonical entry). If claim parsing fails partway (e.g. malformed `is_admin`/`account_level`/`swayrider` sub-object in an otherwise validly RS256-signed token), `VerifyToken` still returns `err == nil` with a partially-zeroed `Claims` struct instead of rejecting the token. In every observed failure mode the zero values are safe defaults (`IsAdmin=false`, empty `AccountLevel`, nil `EmailVerified` treated as unverified), so this isn't an escalation path today — only exploitable if authservice itself ever issues malformed claims, or the claim schema changes in a way that shifts a defaulted field toward a permissive value. Worth fixing for defense-in-depth (propagate/check the error) even though not currently exploitable from outside. Severity: Low/Info.
